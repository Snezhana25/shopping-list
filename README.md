# Shopping-list

## Technical stack: React, TailwindCSS, Vite/Create React App

## Short description of functionality:
- Product carousel (responsive)
- Cart with quantity management and discount

## Implementation highlights:
- Reactive cart state via Context / useCart hook
- Total calculation with discount (more than 5 items = 10%)
- Responsive UI for mobile and desktop

## Instructions for running locally
```
git clone ...
npm install
npm run dev
```
